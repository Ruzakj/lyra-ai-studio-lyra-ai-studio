# Shinobi Clash — 2D Arena

A small original browser game inspired by the feel of classic 2D ninja lane-battle games. It does not use Naruto characters, names, artwork, audio, or other copyrighted assets.

## Run

Open `index.html` in a static web server or deploy the repository to Vercel.

## Controls

- WASD / Arrow keys: move
- J: ranged attack
- K: area skill
- L: ultimate
- Space: dash
